# Event Venue & Parking Map Planner

Plan event entrances, parking, accessible routes, first aid and visitor points on a clear shareable venue map. Export a lightweight SVG without a backend.

Browser-only, privacy-first and serverless. Leaflet + OpenStreetMap tiles; no address upload or backend. Supports English, Turkish, German, French, Spanish, Italian, Dutch, Swedish, Danish, Norwegian, Finnish, Chinese and Portuguese.
